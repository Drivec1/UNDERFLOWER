========================================================
  网页请求  ——  格式说明
========================================================

【怎么装】

  项目 → 项目设置 → 全局 → 自动加载
  路径选：  res://其他(非必要)/网页请求.gd
  节点名填：网页请求
  位置要排在「全局变量」下面（因为要往它里面写东西）


--------------------------------------------------------
【调用格式】
--------------------------------------------------------

  网页请求.发送({
	  "url":    "http://192.168.1.5:8080/加血/100",
	  "方式":   "GET",
	  "请求体": {"玩家": "张三", "加血": 100},
	  "接收":   "当前血量",
  })

  ★ 必须传字典。不是字典就直接报错，不发请求。


--------------------------------------------------------
【字段说明】
--------------------------------------------------------

  url      必须   路径
				  写法：http:// + IP + : + 端口 + / + 要传的信息
				  例：http://192.168.1.5:8080/加血/100
				  信息全放在路径里，不用另外写数据
				  路径里的中文会自动转成 %XX
				  别名：网址、链接、address

  ──────────────────────────────────────────────

  方式     可选   不写就是 GET
				  可写：GET / POST / PUT / PATCH / DELETE / HEAD
				  别名：方法、method

  ──────────────────────────────────────────────

  请求体   可选   默认按 JSON 处理
				  写字典或数组 → 自动转成 JSON
				  写字符串     → 原样发出去
				  只要带了请求体，就自动补上
					  Content-Type: application/json; charset=utf-8
				  带了请求体时，方式一般要写 POST
				  别名：请求体JSON、数据、body、参数、内容

  ──────────────────────────────────────────────

  头       可选   附加请求头，字典形式
				  例：{"Authorization": "Bearer xxx"}
				  你自己写了 Content-Type 就不会被覆盖
				  别名：headers、请求头

  ──────────────────────────────────────────────

  接收     必须   结果写到哪个变量
				  直接写「全局变量」里的变量名
				  不要写路径，不要加点，就写名字
				  例："当前血量"
				  别名：存到、变量、结果变量、接收变量、target

  ──────────────────────────────────────────────

  类型     可选   结果怎么转换
				  自动(默认) / 字符串 / 整数 / 浮点 / 布尔 / JSON
				  「自动」= 按目标变量本来的类型来转
				  别名：convert


--------------------------------------------------------
【结果去哪了】
--------------------------------------------------------

  1) 写进  全局变量.接收的那个名字          ← 主用途
	 如果局域网同步开着，这个值还会自动同步给其他玩家

  2) 同时在  网页请求.结果["那个名字"]  留一份

  3) 会发 完成 / 失败 两个信号

  返回值：
	  成功          → 请求编号（int，从 1 开始）
	  参数不合法    → -1


--------------------------------------------------------
【例子】
--------------------------------------------------------

  1. 最简：只有 url 和 接收（方式默认 GET）

	 网页请求.发送({
		 "url":  "http://192.168.1.5:8080/血量/4321",
		 "接收": "当前血量",
	 })

  2. 带 JSON 请求体

	 网页请求.发送({
		 "url":    "http://192.168.1.5:8080/加血",
		 "方式":   "POST",
		 "请求体": {"玩家": "张三", "加血": 100},
		 "接收":   "服务器数据",
	 })

  3. 快捷方法

	 网页请求.取("http://ip:8080/血量", "当前血量")

	 网页请求.提交JSON("http://ip:8080/加血",
					   {"加血": 100},
					   "服务器数据")

  4. 接信号

	 网页请求.完成.connect(func(编号, 变量名, 值):
		 print("成功 ", 变量名, " = ", 值))

	 网页请求.失败.connect(func(编号, 变量名, 原因):
		 print("失败 ", 变量名, " : ", 原因))


--------------------------------------------------------
【要注意的地方】
--------------------------------------------------------

  · 路径里的中文会自动转码。
	不做这一步的话，Godot 会把裸 UTF-8 直接塞进请求行，
	服务器返回 400，请求根本发不出去。

  · 不写「方式」默认就是 GET。
	带了请求体还写 GET 的话，会给一条警告
	（服务器多半会忽略请求体），但不会自动帮你改成 POST。

  · 「接收」写了不存在的变量名 → 只警告，不报错，
	结果仍然留在 网页请求.结果 里。

  · 服务器返回 500 之类的 → 发 失败 信号，不会写进变量。

  · 导出安卓包记得勾上 INTERNET 权限，否则请求一定失败。
